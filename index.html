Configuraciones rápidas

Modelo físico

E(r) = k Σ dq · R / |R|³
V(r) = k Σ dq / |R|
E = −∇V
k = 8.9875517923×10⁹ N·m²/C²
Las cargas puntuales usan la ley de Coulomb directamente. Las distribuciones lineales y planas se integran numéricamente como sumas de pequeños elementos dq. El dibujo muestra el campo dentro del plano de visualización (corte 2D). Se enmascara una vecindad muy pequeña alrededor de cada elemento para evitar la singularidad numérica en r = 0.
